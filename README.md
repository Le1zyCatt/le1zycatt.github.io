# Le1zy_Catt Personal Site

A Jekyll-powered knowledge archive with an optional immersive system experience. The Chirpy blog remains at `/`, while the Three.js experience lives at `/system/`. Existing Markdown posts, tags, categories, RSS, SEO, and `/posts/:title/` URLs remain unchanged; Three.js, GSAP, and Lenis load only on `/system/`.

## Local development

Install the two toolchains once:

```bash
npm ci
bundle install
```

Build the homepage assets and start Jekyll:

```bash
bash tools/run.sh
```

Open `http://127.0.0.1:4000`. When editing files under `assets/home/src`, run `npm run dev` in a second terminal so Vite rebuilds on change.

## Production check

```bash
bash tools/test.sh
```

This builds the Vite bundle, produces the Jekyll site, and checks internal HTML links.

## Deployment

Push to `main` or `master`. The GitHub Pages workflow installs Node dependencies, builds `assets/home/dist`, builds Jekyll, checks the result, and deploys the generated site. No post URLs or content migration are involved.

## Homepage structure

- `_layouts/immersive-home.html` — immersive system document and Liquid content integration
- `system/index.html` — `/system/` route for the immersive experience
- `_data/projects.yml` — public project modules
- `assets/home/src` — Three.js scene, scroll narrative, terminal, shaders, and styles
- `assets/home/dist` — production homepage assets generated by Vite
- `assets/home/og.png` — social preview artwork
